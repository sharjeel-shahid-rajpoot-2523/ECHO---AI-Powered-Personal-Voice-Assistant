# 🤖 ECHO — AI-Powered Personal Voice Assistant
_____________________________________________________________________________________________________________________________________________________________________________

**ECHO** is an AI-powered personal voice assistant designed to interact with users through natural voice commands and perform useful everyday tasks.
It combines **AI, voice interaction, web technologies, and task automation** to create a simple and intelligent personal assistant experience.

## ✨ Features
_____________________________________________________________________________________________________________________________________________________________________________

ECHO can perform the following tasks using voice commands:
* 🧠 **Answer Questions** — Ask questions and receive intelligent responses.
* 💬 **Send WhatsApp Messages** — Send WhatsApp messages using voice commands.
* 🎵 **Play YouTube Songs** — Search for and play songs on YouTube.
* ⏰ **Set Reminders** — Create reminders for important tasks and events.
* 📅 **Set Date & Time** — Check and work with date and time information.
* 🌐 **Open Websites** — Open requested websites directly through voice commands.

## 🚀 How It Works
_____________________________________________________________________________________________________________________________________________________________________________

1. 🎙️ The user gives a voice command.
2. 🧠 ECHO processes and understands the command.
3. ⚙️ The assistant identifies the required action.
4. 🚀 ECHO performs the requested task.
5. 🔊 The result is communicated back to the user.

## ⚙️ Installation
_____________________________________________________________________________________________________________________________________________________________________________

### 1. Clone the Repository

```bash
git clone https://github.com/sharjeel-shahid-rajpoot-2523/ECHO---AI-Powered-Personal-Voice-Assistant.git
```

### 2. Navigate to the Project

```bash
cd ECHO---AI-Powered-Personal-Voice-Assistant
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Assistant

```bash
python server.py
```

Then open the application in your browser according to the local server address displayed in the terminal.
